# TheAlgorithms/Python fork – agent rules
Follow CONTRIBUTING.md. In short:
- Type hints on all parameters and return values; docstrings explaining the algorithm.
- Doctests for valid AND invalid input; raise ValueError on bad input.
- Return results, never print; no input().
- Descriptive snake_case names; lines <= 88 characters.
- Run `ruff check <file>` and `python3 -m doctest -v <file>` before committing.
- Only change what the issue needs. Do not fix unrelated pre-existing lint warnings.
- Never edit README.md or DIRECTORY.md.
- Never push to or open PRs against TheAlgorithms/Python. PRs go to <you>/Python only.
